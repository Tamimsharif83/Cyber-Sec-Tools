**RedLine**

Redline is a free, Mandiant-developed (now part of Google Cloud) incident response tool for Windows that performs deep forensic analysis on live endpoints. It identifies malicious activity by collecting and analyzing running processes, memory images, file systems, registry data, and network connections to detect threats.

**ProcDOT**


This tool processes Sysinternals Process Monitor (Procmon) logfiles and PCAP-logs (Windump, Tcpdump) to generate a graph via the GraphViz suite. This graph visualizes any relevant activities (customizable) and can be interactively analyzed.


Link: https://www.cert.at/en/downloads/software/software-procdot
